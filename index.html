Mode d'emploi

Installation

Trois minutes, une seule fois par script.

Télécharger

Ouvrez la fiche du script et cliquez sur Télécharger. Décompressez le dossier où vous rangez vos scripts, par exemple Documents/PixInsight/scripts.

Déclarer le dossier

Dans PixInsight : Script › Feature Scripts…, puis Add, choisissez le dossier, et Done. Le script apparaît dans le menu indiqué sur sa fiche.

Ou l'exécuter directement

Sans installation : Script › Execute Script File… puis sélectionnez le fichier .js. Pratique pour un essai.

Les scripts marqués « moteur V8 » demandent PixInsight 1.9 ou plus récent. IA Stamp a aussi besoin de Python : le guide INSTALLATION_PYTHON.md est fourni dans son archive.

À propos

Je suis Olivier, photographe et astrophotographe. Ces scripts sont nés de besoins concrets, rencontrés au fil de mes propres traitements, quand l'outil qui convenait n'existait pas.

Ils sont gratuits. Le code source est sur GitHub : un bug, une idée, une amélioration ? Ouvrez une issue, c'est le meilleur moyen de me le dire.

Les forks (Foraxx Palette V2, Canon Banding Reduction) restent sous la licence de leurs auteurs d'origine, cités sur chaque fiche.
